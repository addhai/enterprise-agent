## 二、三态诚信声明（贯穿全链路）

- **【已实现】**：LangGraph 7 节点编排、RAG 混合检索、MCP 38 工具、RBAC 越权 403、compose 多副本部署、Grafana 可观测面板。
- **【架构就绪未运行化】**：多租户 + RBAC 双重隔离（SQL 级 + 向量级），运行态仅 `default` 单租户（X9/D6）。
- **【演示回退】**：12 服务长时间联跑（milvus 内存 2G 卡点 R-01，当前用 chroma 规避）；云资源查询默认 `ALIYUN_DEMO_FALLBACK=true` 回退样本（红线约束）；RAG 三 bug 已修复 + 单测复验通过（pytest 全绿）。

## 三、P5 突出重点（按项目设计目标规划）

1. **红线第一卖点**：真实密钥（LLM key / 阿里云 AK / JWT secret）永不上公网，仅 localhost / 可吊销 demo key 对外演示。
2. **三态诚信部署双路**：MVP = 私有化 docker compose 多副本（api/ws replicas:2 + chroma）；完整版 = K8s/APISIX 多 AZ 云原生路径，不夸大演示态。
3. **多租户 + RBAC 双重隔离**：核心架构卖点，运行态单租户诚实声明 + 架构就绪。
4. **可观测 / 高可用闭环**：RTO≤15min 多副本自动重启、Grafana 12 面板 8 告警。
5. **IAM / 审计合规**：JWT HS256 + RBAC0/ABAC + 审计字段 who/what/when/where/result **+ tenantId + traceId**。

## 四、部署↔安全对账（G5 前完成）

安全设计裁定部署设计留的 6 处重叠区，反向引用部署章节，一致无冲突：

- KMS = HashiCorp Vault（自托管零服务费）/ 云 KMS 动态拉取 + 轮转（周期基线 90 天）
- 审计保留期 = ≥ 365 天（1 年），5 维度字段 + tenantId + traceId
- 完整版启用 WAF（OWASP Top 10）、出网仅放行 E-01/E-02 白名单、mTLS 完整版可选
