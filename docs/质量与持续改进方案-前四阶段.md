### 2.2 缺陷分级
- **严重(S1)**：生产服务不可用、数据越权/泄露、CI 门禁被破坏。
- **主要(S2)**：AI 准确率/幻觉超阈值、P95 超 2 倍、单测覆盖率跌破门禁。
- **轻微(S3)**：文档/日志瑕疵、非关键告警。

### 2.3 抽样边界与判定
- 域 A 全量（CI 强制）；域 B 抽样 + 全量异常捕获；域 C 全量实时监控 + 周复盘。
- 零分母处理：无对话样本周，域内 B 指标标记为"无数据"，不计入达标率分母。

## 第 3 阶段 · 问题闭环

### 3.1 登记与 ID 规则
- 不合格项统一编号：`QM-YYYY-NNN`（如 QM-2026-001）。
- 记录字段：**ID、对象、严重度、责任角色、状态、时限、证据、验收标准**。

### 3.2 闭环流程
1. **登记**：来源 CI 失败 / 监控告警 / 抽样评估 / 客诉。
2. **分级**：S1/S2/S3（见 2.2）。
3. **遏制**：S1 立即回滚/熔断/降级（如停灰度、切 fallback）；S2 限流+定位；S3 排期。
4. **处置**：修复 / 让步接收 / 停用。让步接收须人工审批留痕。
5. **责任**：明确到角色（开发 / SRE / AI 评估 / 质量负责人）。
6. **验证**：复测 + 证据回读，确认达标。
7. **关闭**：满足验收标准后关闭；S1/S2 需质量负责人复核。
8. **重开**：同对象复发或新证据出现，重开并升级。
9. **升级**：S1 超 4h 未遏制、或 7 日内同根因复发 2 次 → 升级至负责人 + 复盘。

### 3.3 时限基线（草案）
| 严重度 | 遏制时限 | 关闭时限 |
|---|---|---|
| S1 | ≤ 30 分钟 | ≤ 24 小时 |
| S2 | ≤ 4 小时 | ≤ 5 个工作日 |
| S3 | 排期 | ≤ 10 个工作日 |

### 5.2 完整走查示例：QM-2026-001「AI 幻觉导致错误 ECS 操作建议」
- **D0 征兆**：坐席按 AI 建议重启了错误 ECS 实例，影响生产业务。
- **D1 团队**：AI 评估（lead）、开发、SRE、安全。
- **D2 问题(5W2H)**：What=回答给出不存在/错误的实例 ID；When=2026-08 某会话；Where=`/ws/chat`；Who=坐席执行；Why=模型编造了未检索到的资源；How=未做真实 API 校验即输出；How much=1 次误操作，1 业务受影响。
- **D3 遏制**：高风险操作前插入"真实云 API 二次确认"闸门；RAG 置信度低于阈值时强制拒答转人工。
- **D4 根因**：
  - **发生原因（5 Why）**：输出含不存在资源 → 模型未检索到真实资源 → 用训练记忆编造 → prompt 未强制工具调用 → 缺资源真实性校验环节。
  - **逃逸原因（5 Why）**：错误回答未被拦截 → 缺"资源 ID 存在性"校验 → 校验逻辑未覆盖输出层 → 评估未覆盖该场景 → 缺自动化红队用例。
- **D5 永久纠正（发生）**：强制工具调用获取真实资源列表（`FallbackProvider` 真实优先）；低置信度转人工；将"资源真实性"写入 capability-contract。
- **D6 逃逸纠正**：输出层加"资源 ID 存在性校验 + 越权拦截"；补充红队评估集覆盖编造资源场景。
- **D7 预防再发（CAPA）**：
  - CA-1：资源真实性校验纳入 CI 红队用例（开发，2 周）。
  - CA-2：护栏模式沉淀为 skill/文档，跨 Agent 复用（AI 评估，1 周）。
  - CA-3：能力契约增加"禁止无依据资源引用"条款（安全，1 周）。
- **D8 关闭条件**：红队集通过率 ≥ 99% 且连续 30 天无同类复发 → 关闭并复盘。

### 5.3 有效性验证（实施验证 vs 有效性验证分离）
- **实施验证**：措施已部署（代码合并、护栏上线），由 CI/部署记录证明。
- **有效性验证**：幻觉率 ≤ 3% 维持 30 天、红队通过率 ≥ 99%、周抽样无同类问题。
- **复发监控**：周 AI 抽样 + 自动告警；同根因 7 日内复发 2 次自动升级。

## 第 6 阶段 · 供应商与指标

### 6.1 供应商质量（外部依赖治理）
将 AI 平台的外部依赖映射为"供应商"：
| 供应商类型 | 示例 | 治理要点 |
|---|---|---|
| LLM/推理服务 | 商业大模型 / 本地模型 | 准入资质、输出稳定性、密钥红线 |
| 云资源 | Aliyun ECS/RDS/SLB/Redis + 云监控 | 接入前连通性与签名校验（`aliyun_client` 手写 RPC 签名） |
| 嵌入/重排模型 | BGE / gte-reranker | 检索质量、版本变更回归 |
| MCP 工具/外部 API | 各业务系统 | 契约校验、超时/降级 |
| 向量库 | Milvus | 内存/稳定性、备份 |

- **准入**：资质 + 合规 + 密钥安全红线审查；接入前 IQC（连通性 + 正确性验证）。
- **审核**：季度；**评分卡**（维度/权重/数据源/阈值）：可用性 30%、准确率 30%、合规 20%、时延 10%、支持 10%。
- **整改**：不达标降级或替换；高风险供应商停用须人工审批留痕。

### 6.2 指标看板（分子/分母/周期/阈值/零分母/钻取）
**域 A 交付**
| 指标 | 分子 | 分母 | 周期 | 阈值 | 零分母 |
|---|---|---|---|---|---|

| SAST 高危数 | B/H 计数 | — | 每次 CI | 0 | — |
| CI 通过率 | 通过 job | 总 job(4) | 每次 CI | 100% | — |

**域 B AI**（基线：准确率/幻觉待标注集）
| 指标 | 分子 | 分母 | 周期 | 阈值 | 零分母 |
|---|---|---|---|---|---|
| 回答准确率 | 正确数 | 评估样本数 | 周 | ≥ 95% | 周无样本→"无数据" |
| 幻觉率 | 幻觉数 | 样本数 | 周 | ≤ 3% | 同上 |

| 工具调用成功率 | 成功调用 | 总调用 | 周 | ≥ 99% | — |

**域 C 运行**（数据源 Prometheus/Grafana，现状已出数）
| 指标 | 分子 | 分母 | 周期 | 阈值 | 零分母 |
|---|---|---|---|---|---|
| 可用性 | (1 − 不可用分钟) | 总分钟 | 滚动 | ≥ 99.5% | — |
| P95 延迟 | histogram P95 | — | 实时 | ≤ 800ms | — |
| 错误率 | 5xx+业务错误 | 总请求 | 实时 | ≤ 0.5% | — |

**钻取路径**：总览 → 按服务(api/rag/worker) → 按租户 → 按指标 → 明细日志。
**数据质量**：域 A/C 自动采集（CI/Prometheus）；域 B 由评估表/红队集导入，缺失时标注"无数据"不伪造。

### 6.3 Pareto（缺陷分布，用于优先级）
按"严重度 × 频次"排定改进优先级；注意**不以频次替代严重度**——S1 无论频次均优先。示例类别：AI 幻觉、延迟超标、覆盖率跌破、越权风险、依赖故障。
