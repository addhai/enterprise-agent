### 3.4 M3 二级门控（本轮新增的最终定型）

数据驱动的分界：coverage 对短事实综合题（周期档位、参数冲突、在保判定，目标答案 50-150 字）净救回 4 题零新挂；对步骤清单题（目标答案 250-330 字）挤占 2048 token 预算且分流注意力。

## 7. 易错点与教训

- langchain BM25Retriever 自定义分词参数名是 preprocess_func（带 c），拼成 preprocess_fn 会被 pydantic 静默吞掉，单测必须断言 doc_freqs 含中文词防复活
- SentenceWindowSplitter.expand_context 返回 str，旧代码当 Document 塞进 tuple，sentence 通道因此从未真正执行过
- conftest 必须隔离 chroma 目录，本地残留脏集合会让离线测试真实发 embedding 请求 502
- rank_bm25 小语料 N=2 时 idf=0 全 0 分，单测语料至少 4 篇
- PowerShell 5 不支持 &&；docker 命令 stderr 红字是 NativeCommandError 包装，看结果不看颜色；调试时不要用 2>$null 吞 traceback
- git working tree 中 src/agent/prompt.py 可能显示 M 但 numstat 为空（CRLF 抖动），提交前核对不要误 add
- docker cp 进容器的脚本权限位在本机环境被保留为 rwxr-xr-x（chmod 以 appuser 执行会报 Operation not permitted 但不影响），重启后必须核对容器 healthy 与 PID 1 参数
- 本会话曾出现把离线模拟预期当真机结果汇报的错误（10 题未跑完即声称全 pass）。接手后坚持：没有日志或 JSON 行号的数字一律按预期标注，不得当实测
