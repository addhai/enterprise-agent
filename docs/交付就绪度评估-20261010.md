   - WorkflowTab 的 DAG 编排存进程内存（src/graph/workflow_dag.py:489），不驱动生产问答图，全仓仅 evaluation.py:241 调用
   - HITL 审批无任何业务触发源，request_approval 调用方仅测试，存储为进程内字典（src/integrations/humanloop.py:113），且 checkpointer 是 MemorySaver（src/graph/workflow.py:146-148），重启即丢

3. 与离线形态不匹配

   - "流式"为整段生成后按句号正则切段的假流式（src/websocket/routes.py:1045-1085），首字延迟等于整轮耗时，真 StreamingEngine 仅测试引用
   - A2A 专家委托工具无条件注册，SDK 缺失时返回代码内硬编码旧文案（src/agent/tools.py:1011-1018、src/protocols/perf_agent.py:30）；agent_registry 注册 4 个 localhost:900x 幽灵服务，健康检查持续报无意义错误
   - 云资源工具无密钥时回退写死的阿里云样本资产（src/mcp_tools/cloud_provider.py:31），LLM 可能把样本当真实资产回答

卫生问题：生产启动无条件尝试 seed 演示工单（src/api/server.py:199-204，src/seed.py:21-29，无环境开关）；文档解析失败时 chunk_count 写死 42（src/api/knowledge.py:535-536），掩盖零切片故障。

### 2.3 安全与合规（48 分，三个高危经主审人逐行复核）

高危（建议上线前必须修复）：

1. **H1 匿名跨租户 RAG 入口**：`POST /api/v1/chat` 无任何鉴权依赖，tenant_id 与 user_access_levels 直接取自请求体，权限缺省四级全开（src/api/routes.py:194-213）。任意能访问 8000 端口者可令 RAG 按任意租户检索。主审人已读码确认
2. **H2 坐席 WS 零鉴权**：`/ws/agent/{agent_id}` accept 后直接注册，agent_id 客户端自报，无 token、无角色、无 Origin 校验（src/websocket/routes.py:1255-1269）；agent_reply 不校验该连接是否为被分配坐席（src/websocket/dispatcher.py:210-244），知道活 session_id 即可向终端用户冒充人工坐席发消息。主审人已读码确认
3. **H3 会话 IDOR**：WS resume_session 拿到任意 session_id 即挂载，无 owner/tenant 归属校验（src/websocket/routes.py:247-296）；底层 message_list 无租户过滤（src/db/repositories.py:801-813），REST 侧的归属校验在 WS 侧被绕过。主审人已读码确认
4. **H4 边界无防线**：生产交付形态仅映射宿主 8000 明文 HTTP，compose 内无网关无 TLS（deploy/prod/docker-compose.prod.yml:56-57），Redis 无密码（:198-213）；应用层零限流、登录无失败锁定，而 docs/delivery/安全设计.md:80 声称"5 次失败锁定 15 分钟"，代码不存在

中危：

- CORS `allow_origins=["*"]` 与 allow_credentials=True 同开（src/api/server.py:133-139），WS 无 Origin 校验
- JWT_SECRET 环境变量若显式置空字符串会跳过随机密钥兜底，空 HMAC 密钥也能验签且启动不失败（src/config.py:341-344）
- 启动无条件 seed admin/admin123 等默认账号，无强制改密（src/db/seed.py:15-48）；注册端点向任意已知租户开放自助注册（src/api/auth.py:201-245）
- Chatwoot webhook 未配 token 时 return True 跳过验签（src/api/chatwoot.py:48-52）
- 通用操作审计表不存在，models.py 11 张表仅 config_audit_logs（src/db/models.py:213-230）；登录、角色变更、工单、删除会话无审计落库；MCP 审计为进程内 TTL 7 天
- 供应链：Python 依赖全部 `>=` 下界不 pin（requirements*.txt），CI 无 pip-audit/safety/osv，无 dependabot，前端无 npm audit；Semgrep 以 `|| true` 不阻断（.github/workflows/ci.yml:115）
- 隐私：对话全量明文落 Postgres，无 TTL、无匿名化、无静态加密；终端用户无自助删除与导出入口；conversations 删除不带租户校验（src/api/conversations.py:65-76）
- OutputGuard 定义了 PII 与密钥检测但全仓零调用（src/safety/output_guard.py:6-70）
- 低危：异常详情回传客户端 200 字符（src/websocket/routes.py:554-560）、JWT 走 URL query 入访问日志

正向基础（避免一刀切评价）：bcrypt 12 rounds 加旧 SHA256 自动升级、JWT 随机密钥兜底设计、全 ORM 无 SQL 拼接、文件上传三重校验（扩展名白名单加 basename 清洗加 realpath 越界闸门，src/api/knowledge.py:46-125）、配置审计 REDACTED 落库、Bandit/Gitleaks 阻断式 CI、非 root 镜像（uid 10001）、.env 不入镜像。安全意识在上游水平，失分集中在边界端点漏网与文档过度承诺。

工厂内网的威胁模型辩证：H4 的明文与无限流在物理隔离内网中可利用性低于公网产品，建议按"内网横向移动风险"评估而非直接套公网标准；但 H1/H2/H3 是任何能访问 8000 端口的内网主机即可利用的越权，与是否公网无关，不接受以"内网"为由豁免。
