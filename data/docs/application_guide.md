\## 第一章 产品概述



\### 1.1 产品简介

ThermoView T100 是一款便携式非接触红外测温仪，通过接收物体表面红外辐射实现温度测量，适用于工业设备巡检、电气检测、暖通维护、制程监控等场景。



\### 1.2 核心参数速查

| 参数项 | 规格 |

|--------|------|

| 测温范围 | -20℃ \~ 500℃ |

| 测温精度 | ±1.5℃（常温段） |

| 距离系数 D:S | 12:1 |

| 光谱响应 | 8\~14μm |

| 发射率可调范围 | 0.10 \~ 1.00 |

| 响应时间 | ≤300ms |

| 激光定位 | 单点红光，可开关 |



\### 1.3 测量原理简述

一切温度高于绝对零度的物体都会向外辐射红外线，辐射强度与物体温度相关。本仪器通过红外传感器接收被测物体辐射能量，经算法换算为表面温度值。



> ⚠️ 仪器测量的是物体\*\*表面温度\*\*，不是内部温度；测量值受物体表面发射率影响。

\### 2.1 按键功能说明

| 按键 | 功能 | 操作方式 |

|------|------|----------|

| POWER | 开机/关机 | 长按2秒开机，长按3秒关机 |

| MODE | 功能模式切换 | 短按切换测量模式 |

| MAX/MIN | 最大/最小值锁定 | 测量中短按锁定，再按切换 |

| ▲ / ▼ | 参数上调/下调 | 设置菜单中调节数值 |

| BACKLIGHT | 背光开关 | 短按开启/关闭屏幕背光 |

| SAVE | 数据存储 | 读数稳定后短按保存 |

| LASER | 激光开关 | 短按开启/关闭定位激光 |

| BACK | 返回 | 短按返回上一级菜单 |



\### 2.2 标准测量步骤

步骤 1：长按 POWER 键开机，等待仪器自检完成（约 2 秒）

步骤 2：确认当前环境，仪器在现场静置 5\~10 分钟，使机内温度与环境平衡

步骤 3：根据被测物体材质，在设置菜单中调整发射率（见第三章各行业参数表）

步骤 4：开启激光定位，将红点对准被测区域中心

步骤 5：保持仪器与被测表面垂直（夹角≤30°），在额定距离内稳定握持

步骤 6：等待读数稳定（约 0.5\~1 秒），读取温度值

步骤 7：如需记录，短按 SAVE 键保存当前数据

步骤 8：测量完成，长按 POWER 键关机



\### 2.3 测量距离与光斑尺寸

距离系数 D:S = 12:1，即测量距离每增加12cm，光斑直径增加1cm。



| 测量距离 | 光斑直径 | 适用被测物最小尺寸 |

|----------|----------|-------------------|

| 10cm | 0.8cm | ≥1cm |

| 30cm | 2.5cm | ≥3cm |

| 50cm | 4.2cm | ≥5cm |

| 100cm | 8.3cm | ≥10cm |



> 💡 关键原则：被测物体尺寸必须\*\*大于光斑尺寸\*\*，确保光斑完全落在被测表面上，否则会混入背景温度导致读数不准。



\### 2.4 发射率设置参考表

| 材质类型 | 发射率建议值 |

|----------|-------------|

| 人体皮肤 | 0.95 |

| 水、冰 | 0.92\~0.96 |

| 木材、纸张、塑料 | 0.90\~0.95 |

| 橡胶、沥青 | 0.90\~0.95 |

| 氧化金属表面 | 0.60\~0.80 |

| 红砖、混凝土 | 0.85\~0.93 |

| 油漆表面（非光泽） | 0.90\~0.95 |

| 光泽金属/抛光金属 | 0.10\~0.30 |

| 玻璃 | 0.85（注意：红外无法穿透玻璃测内部） |



> 发射率设置偏差0.1，可能导致读数偏差5\~10℃，高精度测量前务必确认材质发射率。

\## 第三章 分行业应用指南



\### 3.1 电力行业应用



\#### 适用场景

配电柜触点测温、变压器温升检测、电缆接头测温、电机绕组测温、母线排测温、隔离开关触头测温、电容器外壳测温。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 正常温度参考 | 报警阈值建议 |

|----------|-----------|-------------|-------------|

| 配电柜铜排触点 | 0.20\~0.30 | 40\~60℃ | ≥80℃ |

| 电缆接头 | 0.90（外包绝缘层） | 30\~50℃ | ≥70℃ |

| 变压器外壳 | 0.85\~0.95 | 40\~65℃ | ≥85℃ |

| 电机绕组（外壳） | 0.85\~0.90 | 40\~70℃ | ≥90℃ |

| 隔离开关触头 | 0.20\~0.30 | 30\~50℃ | ≥75℃ |



\#### 操作要点

1\. \*\*安全第一\*\*：测量带电设备必须保持安全距离，遵守电力安全规程，严禁仪器触碰带电体。10kV以下安全距离≥0.7m，35kV≥1.0m。

2\. \*\*金属触点发射率低\*\*：铜、铝等光亮金属触点发射率0.2\~0.3，必须调低发射率，否则读数严重偏低。

3\. \*\*避免阳光干扰\*\*：户外测量尽量选择阴天或清晨、傍晚，阳光直射会使读数偏高5\~15℃。

4\. \*\*三相对比法\*\*：对三相电路，测量同一回路三相对应部位，温差超过10℃即为异常发热隐患。

5\. \*\*趋势分析\*\*：记录同一部位不同时间的温度值，建立温度趋势曲线，温升速率比绝对温度更有预警价值。

6\. \*\*负荷记录\*\*：测温同时记录设备负荷电流，同一温度在不同负荷下意义不同。



\#### 常见问题

\- \*\*Q：配电柜玻璃门关上能测吗？\*\*

&#x20; A：不能。红外无法穿透普通玻璃，必须打开柜门或使用红外透过窗口（锗玻璃）测量。

\- \*\*Q：铜排氧化了发射率怎么设？\*\*

&#x20; A：氧化层会提高发射率，氧化铜排建议设0.6\~0.7，光亮新铜排设0.2\~0.3。

\### 3.2 制造业应用



\#### 适用场景

模具测温、注塑机料筒测温、热处理工件测温、设备轴承测温、焊接件测温、压铸模温检测、辊筒表面测温。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 正常温度参考 |

|----------|-----------|-------------|

| 注塑机料筒（氧化） | 0.60\~0.80 | 180\~280℃ |

| 模具表面（氧化钢） | 0.60\~0.80 | 60\~150℃ |

| 轴承座外壳 | 0.85\~0.90 | 40\~70℃ |

| 热处理工件（氧化） | 0.60\~0.80 | 200\~500℃ |

| 焊接接头 | 0.80\~0.90 | 100\~300℃（焊后） |



\#### 操作要点

1\. \*\*高温物体单次测量不超过3分钟\*\*：避免仪器长时间靠近高温物体导致内部过热，影响精度甚至损坏。

2\. \*\*运动部件注意安全\*\*：测量旋转辊筒、运动模具时，注意仪器与设备的安全距离，防止碰撞卷入。

3\. \*\*氧化金属发射率较高\*\*：制造业中模具、料筒多为氧化表面，发射率建议0.6\~0.8，不要按光亮金属设置。

4\. \*\*表面清洁\*\*：被测表面有油污、脱模剂、氧化层剥落时，先清洁或在清洁区域测量。

5\. \*\*料筒分段测量\*\*：注塑机料筒沿轴向分进料段、压缩段、均化段，逐段测量对比，判断加热圈是否正常。

6\. \*\*轴承测温位置\*\*：测量轴承座外圈最接近滚动体的位置，不是轴承端盖，端盖温度通常偏低5\~10℃。



\#### 常见问题

\- \*\*Q：测量光亮的新模具读数偏低怎么办？\*\*

&#x20; A：在被测区域贴一小块哑光黑色胶带（发射率0.95），等胶带温度与模具平衡后测量胶带温度，或用接触式温度计比对后修正发射率。

\- \*\*Q：热处理工件发红了能测吗？\*\*

&#x20; A：500℃以上工件开始可见红光，本仪器量程上限500℃，超量程会显示"HI"，需更换大量程型号。

\### 3.3 暖通空调（HVAC）应用



\#### 适用场景

空调出风口温度、管道表面温度、换热器测温、电机温升、压缩机外壳测温、地暖管道测温、风道温度分布。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 正常温度参考 |

|----------|-----------|-------------|

| 空调出风口（塑料） | 0.90\~0.95 | 制冷10\~16℃ / 制热35\~45℃ |

| 金属风管（镀锌） | 0.20\~0.30 | 接近送风温度 |

| 保温管道表面 | 0.90 | 接近环境温度 |

| 换热器翅片 | 0.90 | 制冷5\~12℃ / 制热40\~50℃ |

| 压缩机外壳 | 0.85\~0.90 | 40\~80℃ |



\#### 操作要点

1\. \*\*出风口测量\*\*：在出风口中心点测量，避开边缘涡流区，仪器距风口10\~20cm，待读数稳定。

2\. \*\*管道选直管段\*\*：测量管道表面温度时，选择直管段，避开弯头、阀门、法兰处（这些部位温度场不均匀）。

3\. \*\*保温层≠内部温度\*\*：测量保温层表面温度只能评估保温效果，不能代表管道内介质温度，需在管道裸露处或加装测温座测量。

4\. \*\*换热器测量\*\*：测量进风侧和出风侧温度，计算换热温差，判断换热器是否脏堵。

5\. \*\*压缩机测温\*\*：测量压缩机吸气口、排气口、外壳顶部三点，温差异常可判断制冷剂是否充足。

6\. \*\*地暖检测\*\*：沿地面网格扫描，温度异常区域对应管道走向，可判断管道是否堵塞或泄漏。



\#### 常见问题

\- \*\*Q：制冷出风口测出来15℃正常吗？\*\*

&#x20; A：家用空调制冷出风口正常8\~15℃，15℃偏高，可能滤网脏堵、制冷剂不足或蒸发器结霜。

\- \*\*Q：镀锌风管发射率设多少？\*\*

&#x20; A：光亮镀锌板发射率约0.2\~0.3，但积灰后会升高，建议贴一小块电工胶带测量。

\### 3.4 食品加工行业应用



\#### 适用场景

食品表面温度检测、烤箱内部温度、冷库温度、传送带食品测温、包装封口温度、烹饪中心温度（表面法）。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 备注 |

|----------|-----------|------|

| 肉类表面 | 0.95 | 生肉表面含水，发射率高 |

| 烘焙食品 | 0.90\~0.95 | |

| 不锈钢传送带 | 0.20\~0.30 | 光亮金属低发射率 |

| 烤箱内壁（氧化） | 0.80\~0.90 | |

| 塑料包装膜 | 0.90 | |



\#### 操作要点

1\. \*\*食品表面≠中心温度\*\*：红外只能测表面，食品安全要求的中心温度需用探针温度计确认，红外用于快速筛查。

2\. \*\*冷库测量注意凝露\*\*：从常温进入冷库，镜头会凝露，等待仪器温度平衡（约10分钟）或擦拭镜头后测量。

3\. \*\*传送带测量\*\*：测量运动中的食品，保持仪器与食品同步移动或在固定位置连续采样取稳定值。

4\. \*\*包装封口温度\*\*：测量封口后立即测封边温度，判断热封温度是否达标，注意发射率按包装材料设置。

5\. \*\*卫生要求\*\*：仪器不得直接接触食品，保持安全距离，定期清洁仪器外壳。

\### 3.5 化工与石油行业应用



\#### 适用场景

管道表面测温、反应釜外壁测温、泵体轴承测温、电机测温、储罐液位检测（温差法）、保温效果评估、法兰泄漏检测。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 备注 |

|----------|-----------|------|

| 保温层外表面 | 0.90 | 评估保温效果 |

| 裸露管道（氧化） | 0.60\~0.80 | |

| 反应釜外壁（油漆） | 0.90 | |

| 泵体/电机外壳 | 0.85\~0.90 | |

| 法兰金属面 | 0.20\~0.30 | |



\#### 操作要点

1\. \*\*防爆区域合规\*\*：在防爆区域使用，确认仪器防爆等级符合区域要求，本型号为普通型，禁止在0区、1区使用。

2\. \*\*保温层测温\*\*：保温层表面温度均匀性可判断保温是否完好，局部高温点对应保温层破损或内部管道泄漏。

3\. \*\*储罐液位检测\*\*：储罐气相段和液相段壁温不同，沿罐壁垂直扫描，温度突变处即为液位高度。

4\. \*\*法兰泄漏检测\*\*：泄漏介质（气体/液体）蒸发吸热，使法兰局部温度偏低，扫描法兰周边可发现早期泄漏。

5\. \*\*高温管道安全距离\*\*：测量高温管道时保持安全距离，防止烫伤，单次测量时间不宜过长。

\### 3.6 汽车行业应用



\#### 适用场景

发动机部件测温、制动盘测温、轮胎测温、排气系统测温、空调系统检测、轴承测温、电子元件测温。



\#### 典型测量对象与发射率

| 测量对象 | 发射率设置 | 正常温度参考 |

|----------|-----------|-------------|

| 发动机缸盖（油漆/氧化） | 0.85\~0.95 | 80\~105℃ |

| 制动盘（氧化铸铁） | 0.60\~0.80 | 常温\~300℃（制动后） |

| 轮胎橡胶 | 0.95 | 40\~60℃（行驶后） |

| 排气管（氧化） | 0.60\~0.80 | 200\~500℃ |

| 散热器 | 0.90 | 80\~95℃ |



\#### 操作要点

1\. \*\*制动盘测温\*\*：车辆行驶制动后，立即测量制动盘表面，左右轮温差超过20%说明制动力分配不均。

2\. \*\*轮胎测温\*\*：测量胎面和胎侧，胎肩温度过高说明气压不足，胎冠过高说明气压过高。

3\. \*\*发动机测温\*\*：熄火后尽快测量，各缸火花塞附近温度对比，温差大说明个别缸工作不良。

4\. \*\*排气系统\*\*：三元催化器前后温差判断催化器是否堵塞（正常前高后低，堵塞后温差减小）。

5\. \*\*注意运动部件\*\*：车辆运行中测量时，远离风扇、皮带等运动部件。

\### 3.7 建筑与楼宇应用



\#### 适用场景

地暖管道检测、外墙保温检测、窗户密封性检测、漏水点排查、电气线路检测、暖通系统平衡调试。



\#### 操作要点

1\. \*\*地暖检测\*\*：地暖开启2小时后，沿地面网格扫描，温度分布应与管道走向一致；局部低温区可能管道堵塞，局部高温区可能管道靠近表面。

2\. \*\*外墙保温\*\*：冬季室内外温差大时，测量外墙内表面，温度均匀说明保温良好，局部低温点对应保温层缺失或冷桥。

3\. \*\*窗户密封\*\*：测量窗框周边，冬季低温缝隙对应漏风点，夏季可配合烟雾法确认。

4\. \*\*漏水排查\*\*：漏水区域水分蒸发吸热，温度略低于干燥区域，可辅助定位漏水路径。

\## 第四章 特殊测量技巧



\### 4.1 低发射率物体测量法

光亮金属（抛光不锈钢、铝板、铜排）发射率低，直接测量误差大。推荐方法：

1\. \*\*贴胶带法\*\*：在被测区域贴一小块哑光黑色聚酰亚胺胶带（发射率0.95），等待热平衡（约1\~2分钟）后测量胶带温度。

2\. \*\*涂漆法\*\*：长期监测点可涂一层薄的哑光黑漆，发射率约0.95。

3\. \*\*对比校准法\*\*：用接触式温度计在同一点测量，反推发射率设置值，后续测量保持相同设置。



\### 4.2 运动物体测量法

1\. 仪器固定在支架上，等待物体经过时连续触发测量

2\. 或仪器与物体保持同步移动，相对静止时读数

3\. 取多次测量的稳定值，舍弃跳变数据



\### 4.3 微小目标测量法

被测物体小于光斑时，读数会混入背景温度：

1\. 尽量靠近测量，缩小光斑

2\. 用与目标温度不同的背景板遮挡背景

3\. 读数需注明"含背景影响，仅供参考"



\### 4.4 温差测量法

很多应用关注的是温差而非绝对温度：

1\. 测量基准点温度，记录为T1

2\. 测量对比点温度，记录为T2

3\. 计算ΔT = T2 - T1

4\. 发射率设置相同的情况下，温差精度高于绝对温度精度

\## 第五章 测量误差来源与规避



| 误差来源 | 影响 | 规避方法 |

|----------|------|----------|

| 发射率设置错误 | 读数偏高或偏低5\~20℃ | 按材质正确设置，低发射率物体用胶带法 |

| 光斑大于被测物 | 混入背景温度 | 靠近测量，确保光斑完全覆盖被测物 |

| 阳光直射 | 读数偏高5\~15℃ | 遮阳、阴天测量、或遮挡被测区域 |

| 仪器未温度平衡 | 读数漂移 | 进入新环境静置5\~10分钟 |

| 镜头脏污/凝露 | 读数偏低、不稳定 | 清洁镜头，等待凝露蒸发 |

| 测量角度过大 | 读数偏低 | 保持垂直，夹角≤30° |

| 背景有高温物体 | 读数偏高 | 遮挡背景热源，或改变测量角度 |

| 烟雾/蒸汽遮挡 | 读数偏低、跳变 | 等待烟雾散去，或在无遮挡位置测量 |

| 透过玻璃测量 | 无法测内部，测的是玻璃表面温度 | 必须打开窗口或使用红外透过窗口 |

\## 第六章 应用案例



\### 案例1：配电柜触点过热预警

\*\*背景\*\*：某工厂配电柜定期巡检

\*\*操作\*\*：三相铜排触点逐一测量，发射率设0.25

\*\*发现\*\*：A相触点78℃，B相45℃，C相48℃，A相比其他两相高30℃以上

\*\*处理\*\*：停电检查，发现A相触点松动氧化，紧固处理后复测48℃，避免了一次停电事故



\### 案例2：注塑机料筒加热圈故障

\*\*背景\*\*：注塑产品出现飞边，怀疑料筒温度不均

\*\*操作\*\*：料筒沿轴向分5点测量，发射率0.7

\*\*发现\*\*：第3段温度显示220℃但实测165℃，加热圈损坏

\*\*处理\*\*：更换加热圈后温度恢复正常，产品质量稳定



\### 案例3：空调制冷效果差排查

\*\*背景\*\*：办公室空调制冷效果差

\*\*操作\*\*：测量出风口14℃（偏高），蒸发器进风28℃，出风14℃，换热温差14℃（正常应≥10℃）

\*\*进一步\*\*：测量压缩机吸气口5℃，排气口65℃，判断制冷剂不足

\*\*处理\*\*：补充制冷剂后出风口降至9℃，制冷恢复正常

\## 第七章 通用测量注意事项（强制）



1\. ❌ \*\*禁止透过玻璃、透明塑料测量\*\*——红外无法穿透，测到的是玻璃表面温度

2\. ❌ \*\*禁止测量有烟雾、蒸汽遮挡的目标\*\*——会吸收红外辐射，读数偏低

3\. ❌ \*\*禁止将仪器激光直射人眼\*\*——可能造成视网膜损伤

4\. ❌ \*\*禁止超量程使用\*\*——超过500℃显示"HI"，长期超量程可能损坏传感器

5\. ✅ 测温仪与被测表面夹角尽量垂直，不超过30°

6\. ✅ 目标尺寸必须大于光斑尺寸，保证完全覆盖

7\. ✅ 测量前在现场环境静置5\~10分钟，让仪器温度与环境平衡

8\. ✅ 定期清洁镜头，保持光学窗口干净
